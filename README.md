# Interaktiver Zahlenstrahl (Wordpress Plugin)

## Beschreibung
<p>Stellt einen interaktiven, zoombaren Zahlenstrahl per Shortcode [zahlenstrahl] zur Verfügung.</p>

## Shortcode
<code>[zahlenstrahl]</code>
